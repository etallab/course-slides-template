\begin{frame}
  \frametitle{Getting Help}

  I want to help you learn.
  Here are some things to do and not to do:

  \begin{columns}[t]
    \begin{column}{.5\textwidth}
      \begin{itemize}
      \item \textbf{Do} send me the full source code as an attachment.
      \item \textbf{Do} point out the part of the program where you have a question or where you thing there is a problem.
      \item \textbf{Do} tell me the error that you are getting.
      \item \textbf{Do} tell me what you have done so far.
      \end{itemize}
    \end{column}

    \begin{column}{.5\textwidth}

      \begin{itemize}
      \item \textbf{Don't} send just a fragment of your code.
      \item \textbf{Don't} include only a screenshot of your program.
      \item \textbf{Don't} copy and paste your text into the mail message.
      \end{itemize}
      
    \end{column}
  \end{columns}
    
\end{frame}
